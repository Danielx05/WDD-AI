# Summer Camp Web Layouts

Two static HTML and CSS layout exercises from a 2024 summer camp.

## View the exercises

- [camp1.html](camp1.html) explores a welcome banner and stacked content blocks.
- [camp2.html](camp2.html) adds an image column alongside placeholder content. Its image loads from an external source.

Download or clone this repository and open either HTML file in a browser. There is no build step.

## What I practiced

I experimented with spacing, typography, color, and floated columns to structure static pages.
